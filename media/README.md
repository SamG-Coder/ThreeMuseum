# ThreeMuseum — Director's Cut

[Watch or download the MP4](ThreeMuseum-Directors-Cut.mp4).

- Duration: 120.1 seconds.
- Video: 1280 × 720, 30 fps, H.264, YUV 4:2:0.
- Audio: AAC stereo; an original quiet synthesized score generated by `tools/director-score.py`.
- Capture: actual ThreeMuseum rendering in Microsoft Edge through Playwright.
- Edit: 40 shots, including all 30 installed exhibit positions, architecture, ramp/overlook, map, viewing settings, GLB installation tools, provenance cards, theatre and lounge.

The camera path and captions are in `src/director.js`; `director-timeline.json` records the shot durations. Physical reading plaques and visitor HUD elements are hidden during cinematic shots. The dialog segments show the actual application UI. The film does not represent a physical touch-device test or a benchmark. Specimens are static original interpretations except for the credited Smithsonian CC0 Triceratops.

Capture and encoding completed without reported browser errors. Review frames were checked for shot composition; the encoded video was checked for resolution, duration, codecs and representative frames.
